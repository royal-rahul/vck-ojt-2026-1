# Student Task Manager

Student Task Manager is a beginner-friendly backend web application developed using:

- Python
- Flask
- MySQL
- Bootstrap
- DataTables

## Features

- Student Management
- Attendance Management
- Task Management
- Task Assignment
- Performance Reports
- Attendance Reports
- Login Authentication
- Dashboard Analytics

## Technologies Used

- Python
- Flask
- MySQL
- HTML
- Bootstrap
- jQuery
- DataTables

## Modules

1. Student CRUD
2. Attendance
3. Tasks
4. Student Task Assignment
5. Reports
6. Authentication

## Learning Concepts

- CRUD Operations
- SQL Queries
- INNER JOIN
- LEFT JOIN
- GROUP BY
- Aggregate Functions
- Flask Routing
- Session Management

## Developed For

On-the-Job Training (OJT) Program for IT Students.
